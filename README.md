# Mini-Storage-KB99

Учебная конфигурация «Мини-Склад», разработанная в рамках стажировки по 1С-разработке от КБ-99.

<img width="1470" height="956" alt="Общий вид конфигурации" src="https://github.com/user-attachments/assets/4ade3eba-59b1-4d15-9785-3e32cd4691fd" />

## Функционал конфигурации

Реализован базовый контур складского учёта:
- **Справочники:** «Товары», «Контрагенты»
- **Документы:** «Поступление», «Реализация»
- **Подсистемы:** «Мини-Склад»

### Интерфейс и работа с данными
Реализовано создание и редактирование элементов справочников и документов через стандартные формы:

<img width="740" height="251" alt="Создание элементов" src="https://github.com/user-attachments/assets/91556372-5045-4e5a-baec-3305fd8292fd" />


### Требования

- **Платформа:** 1С:Предприятие 8.3 (версия не ниже **8.3.24**)
- Установленный **Git**

### Установка и запуск

Конфигурация выгружена в исходные XML-файлы. Чтобы развернуть проект:
 - Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/vita282006-glitch/Mini-Storage-KB99.git](https://github.com/username/Mini-Storage-KB99.git)
   cd Mini-Storage-KB99
- Если потребуется, то авторизация git
- Далее открываем пустой конфигуратор 1С(не ранее 8.3.24)
- Конфигурация -> Загрузить конфигурацию из файлов
- Выбираем папку src в колонизованном репозитории
