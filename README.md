# Mini-Storage-KB99

Учебная конфигурация «Мини-Склад», разработанная в рамках стажировки по 1С-разработке от КБ-99.

## Функционал конфигурации

Реализован базовый контур складского учёта:
- **Справочники:** «Товары», «Контрагенты», «ВариантыТоваров» (подчинен «Товарам»), «ДополнительныеСвойстваТоваров» (значения свойств, подчинен ПВХ «СвойстваТоваров»)
- **Документы:** «Поступление», «Реализация» (с контролем остатков и партионным учетом по FIFO)
- **Планы видов характеристик:** «СвойстваТоваров» (для настройки дополнительных реквизитов и характеристик)
- **Регистры сведений:** «ЗначенияСвойствТоваров» (хранение значений характеристик для вариантов товаров)
- **Регистры накопления:**
  - «ОстаткиТоваров» (вид: Остатки — учет остатков и себестоимости в разрезе товаров, вариантов и партий)
  - «Продажи» (вид: Обороты — учет объемов и сумм продаж по товарам и контрагентам)
- **Отчеты:** «ОтчетПоПродажам» (на базе СКД с группировками по товарам и покупателям)
- **Печатные формы:** печатная форма накладной для документа «Реализация»
- **Общие модули:** «РаботаСДокументами» (клиентский пересчет сумм строк)
- **Подсистемы:** «Мини-Склад»

### Требования

- **Платформа:** 1С:Предприятие 8.3 (версия не ниже **8.3.24**)
- Установленный **Git**

### Установка и запуск

Конфигурация выгружена в исходные XML-файлы. Чтобы развернуть проект:
 - Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/vita282006-glitch/Mini-Storage-KB99.git](https://github.com/username/Mini-Storage-KB99.git)
   cd Mini-Storage-KB99
- Если потребуется, то авторизация git
- Далее открываем пустой конфигуратор 1С(не ранее 8.3.24)
- Конфигурация -> Загрузить конфигурацию из файлов
- Выбираем папку src в колонизованном репозитории
